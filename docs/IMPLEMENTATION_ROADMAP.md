## Stage 2 entry and exit

Stage 2 enters after review of this documentation and agreement on the platform targets. iOS and Android are the mobile acceptance targets. Browser support and its storage model may be evaluated separately. Use a common supported Node LTS for Expo, NestJS and Prisma. Record the actual version matrix and installation commands in the Stage 2 repository changes.

1. **Reproducible workspace.** One package-manager version and lockfile. From a clean checkout, documented commands install dependencies, run lint/type-check/tests and build the API and shared contracts. Expo dependency validation and Expo Doctor pass.
2. **Mobile smoke.** Expo Router shell launches on iOS and Android development builds or compatible Expo clients. A settings/configuration smoke proves the URL can be validated and persisted. An Expo SQLite probe writes data and reads it after restart.
3. **Backend smoke.** A NestJS app serves versioned health endpoints and publishes an API version. Missing/invalid configuration fails safely. Liveness stays up during DB loss and readiness returns a non-success response.
4. **Database proof.** Pin matching supported Prisma CLI/client versions. Local and CI MongoDB use an initialized replica set. Validate and generate Prisma client, apply the test schema/indexes, persist and read a test record, prove transaction rollback and exercise duplicate-key enforcement.
5. **CI and secrets.** A PR runs reproducible install, lint, type-check, build, unit tests and isolated MongoDB integration. Config templates contain placeholders, and build/runtime credentials are injected in their respective environments. Repository and mobile bundle checks find no server secrets.
6. **Migration disposition.** Record whether Supabase data exists and who owns any export/cutover. The new scaffold has one configured backend. Keep the Stage 2 PR limited to foundation and verification.

Archive the first-stage evidence with the PR. Auth, application UI and messaging implementation begin only in their designated stages.
