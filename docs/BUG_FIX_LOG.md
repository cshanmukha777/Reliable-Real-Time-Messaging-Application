# Stage 5 bug fix log

| Symptom                                                                                                | Root cause                                                                                                                                     | Fix and verification                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Search returned HTTP 500 on MongoDB                                                                    | Prisma 6.19's native find options decode `maxTimeMS` as a duration object. Passing a bare number failed before MongoDB ran the indexed query.  | Provide the bounded duration value Prisma can decode. Verify the compound text index and run authorized search and equal-timestamp search pagination against MongoDB. |
| Existing token refresh interrupted chat navigation                                                     | The session provider temporarily unmounted authenticated routes for every refresh, discarding the composer and its pending UUID.               | Keep an already authenticated route tree mounted while rotation is in flight. The existing expiry and sign-out paths still clear access.                              |
| Mobile messaging tests failed before running                                                           | Node 24's built-in strip-only TypeScript loader does not emit constructor parameter properties.                                                | Declare fields and assign them explicitly in the portable service and retry state. Run all foundation, auth and messaging unit tests.                                 |
| Signed uploads could otherwise change after verification                                               | A signed PUT remains valid briefly after completion. Reusing its writable object as an attachment would permit changing verified bytes.        | Seal inspected bytes to a separate object key and serve only that key. The real S3 integration checks stored byte equality and scoped access.                         |
| Browser verification showed React warnings over populated routes                                       | Empty string conditions rendered text nodes under React Native views, and the list passed a fragment to a layout callback.                     | Use boolean conditions and native view wrappers. Recapture the inbox, thread, retry, search and members screens using the real backend.                               |
| The CI object-storage probe received a connection reset immediately after Docker started the container | Container startup can finish before the S3 listener is accepting HTTP. The probe retried connection refusals while a reset exited immediately. | Retry transport errors within a bounded readiness window. Run the same real MongoDB and private S3 integration after the service responds.                            |

## Stage 7 fixes

| Symptom                                                                              | Change and regression evidence                                                                                                                                                                       |
| ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A visible draft edit could sit in the former debounce queue                          | The composer starts a SQLite write immediately and visibly tracks the SQLite commit. A child-process SIGKILL follows the acknowledged commit in the regression test.                                 |
| Same-origin native sockets send an Origin even with no browser allowlist             | The upgrade gate recognizes the HTTP(S) origin derived from the endpoint, and still validates cross-origin requests. The live socket suite covers accepted native origin and refused foreign origin. |
| A stale history response could restore content after a cache replacement             | Snapshot rebase fences earlier reads and revocation clears authorized server projections. SQLite tests preserve pending operations while rejecting the obsolete response.                            |
| Concurrent socket commands could cross the four-room cap                             | The gateway serializes commands per socket and bounds its queue. The integration test submits concurrent watch requests and checks command and packet limits.                                        |
| The first Stage 7 CI run sometimes consumed a stale hint when waiting for revocation | The test now waits beyond the pre-write account watermark. The transport and relay tests use their own group conversations so a prior fixture failure cannot change their membership.                |
