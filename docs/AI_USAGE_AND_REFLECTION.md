# AI usage and reflection

OpenAI Codex assisted with reading the repository, drafting Stage 5 code and documentation, comparing the implementation with the specification, and executing automated checks. The test evidence identifies checks actually executed and leaves device checks pending when there is no device evidence. The implementation and discussion should be independently reviewed before assessment.

## Student reflection template

- **What did I use AI for?** Describe specific architecture, code, debugging or documentation tasks and identify one relevant change.
- **What did I change or reject?** Describe a suggested approach, what you changed and why.
- **What did I learn?** Explain one design decision such as membership visibility, duplicate-send handling or private signed transfers in your own words.
- **What did I verify independently?** List the commands or device steps you personally ran, the result and any remaining limits.
