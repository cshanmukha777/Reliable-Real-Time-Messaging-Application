# Design references

The redesign applied [Unslop](https://github.com/heydamir/unslop) by **Damir Sokolovsky**, licensed under [CC BY 4.0](https://github.com/heydamir/unslop/blob/main/LICENSE). The reviewed revision was `620163eedb3529d9cd23a3994ed8d287d06f760d`. I used its audit, ordered passes and reference examples to guide the design. ChatApp’s artwork, layout, components and implementation are original. No example code was copied.

- [Reference implementations](https://github.com/heydamir/unslop/tree/620163eedb3529d9cd23a3994ed8d287d06f760d/examples)

The engraving reference informed the relationship between serif text and warm neutrals. The restrained dashboard chrome informed the use of dividers and one strong signal at a time. A message-delivery rail, personal initial seals and an everyday conversation about meeting during rain ground those choices in ChatApp.

The preview-only coffee photo is by [Julián](https://unsplash.com/photos/a-cup-of-coffee-sitting-on-top-of-a-saucer-wlPGn504tuk), used under the [Unsplash License](https://unsplash.com/license). It was resized and cropped for the fixture attachment. Interface glyphs are from [Lucide](https://lucide.dev/license) using its React Native package.
